# Mini Tienda 🛒

Proyecto web desarrollado con HTML, CSS, JavaScript y Bootstrap que simula una tienda virtual sencilla con carrito de compras dinámico.

## 📌 Descripción

Esta aplicación permite visualizar productos, agregarlos al carrito de compras, eliminar productos individualmente y vaciar completamente el carrito.

El sistema actualiza automáticamente:

- Cantidad de productos agregados
- Total acumulado de la compra
- Estado del carrito

Todo el proyecto fue desarrollado utilizando JavaScript Vanilla y Bootstrap 5 para el diseño responsive.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
